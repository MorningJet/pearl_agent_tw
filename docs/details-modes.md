# 設計詳情頁三種模式

代碼枚舉：`DetailsMode`（`src/pages/details/index.js`）

| 模式 ID | 中文名 | 入口 | 商品明細 | 其餘 UI |
|---------|--------|------|----------|---------|
| `normal` | **普通詳情** | **僅**從 0 開始自己設計的手串（無廣場來源） | SKU 明細 + 運費 | 頂欄標題「設計詳情」；可改名、可發佈 |
| `plaza` | **廣場設計詳情** | 廣場 / 首頁點他人設計卡（訪客） | 設計名稱（當前珠串總價）+ 設計費用 + 運費 | 頂欄標題＝**設計名稱**；設計師條、使用設計 |
| `plaza-edit` | **廣場修改後設計詳情** | 凡設計**最初**來自「使用設計」 | 設計名稱（**當前改珠後總價**）+ 設計費用 + 運費 | 頂欄標題＝**設計名稱**；chrome 同普通詳情 |

## 判定規則（持久）

- 「使用設計」當下寫入 `originPlazaPublishId` + `originDesignFeeTwd`（存進「我的設計」；再發佈則一併寫入發佈快照）。
- **之後無論改多少次、打開多少次**，只要帶有該來源標記 → 一律 `plaza-edit`，**不會**退回 `normal`。
- 只有從未使用過廣場模板、從空白 DIY 做出的設計 → `normal`。
- 訪客點廣場卡 → 仍是 `plaza`（與自己的修改稿無關）。

## 流程示意

```
空白 DIY ──立即製作──► normal

廣場卡片 ──點擊──► plaza
              │
              └──使用設計──► 畫布（可反覆改）──立即製作 / 我的設計再開──► plaza-edit（永久）
```

## 命名約定

- 產品文書：普通詳情 / 廣場設計詳情 / 廣場修改後設計詳情。
- 代碼：`normal` | `plaza` | `plaza-edit`（勿再用 `owner`）。
